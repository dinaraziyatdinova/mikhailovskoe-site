# Михайловское. Усадьба открытий

Одностраничный сайт историко-культурного и научно-просветительского комплекса «Михайловское. Усадьба открытий». Для защиты архитектурного проекта используется условный сценарий: комплекс уже открыт и действует. Это сценарий презентации, а не подтверждение фактического открытия. Язык — русский. HTML, CSS и JavaScript без фреймворков, сборки и внешних сетевых зависимостей.

## Запуск

Откройте `index.html` в современном браузере. Для локального HTTP-просмотра из этой папки можно выполнить:

```sh
python -m http.server 4173
```

Затем откройте http://localhost:4173. Если Python не установлен, используйте любой локальный статический сервер, например расширение Live Server.

## GitHub Pages

Разместите содержимое папки в репозитории и выберите в Settings → Pages публикацию из нужной ветки, папка / (root). Все пути относительные; сайт поддерживает публикацию в подкаталоге репозитория. Отдельная сборка и установка зависимостей не нужны. Файл `.nojekyll` отключает ненужную обработку Jekyll.

## Файлы

- `index.html` — семантическая разметка, русский контент, статические карточки и FAQ.
- `styles.css` — дизайн-система, фирменные цвета, композиции и адаптивные стили.
- `script.js` — меню, модальные окна, фильтрация афиши, переключение маршрутов и появление контента.
- `assets/` — локальные изображения, оригинальная графика и условные концептуальные иллюстрации.
- `assets/SOURCES.md` — происхождение визуальных материалов.

## Работа с содержанием

В посетительских текстах комплекс описан в настоящем времени как действующее культурное учреждение в рамках согласованного презентационного сценария. Точные даты, цены, адреса, часы работы и контакты не вымышлены; онлайн-запись не имитируется.

Главный дом, флигели и исторический парк представлены как действующие пространства. Оранжерея явно выделена как отдельная инициатива: она не построена, не принимает посетителей, её строительство требует согласования.

Для изменения текстов карточек отредактируйте `index.html`. Дополнительные тексты модальных окон находятся в объектах `spaces` и `events` в `script.js`. При добавлении программы согласуйте `data-event` и ключ в `events`, а `data-category` — со значением кнопки фильтра `data-filter`. Тексты тематических маршрутов находятся в объекте `routes`.

Контакты добавляются в блок `.contact-placeholder`. После получения подтверждённых данных обновите также FAQ и информацию для поездки. При появлении реальной записи добавляйте её только вместе с работающим адресом сервиса и утверждёнными условиями.

## Замена иллюстраций фотографиями

Оригинальная панорама из фирменного стиля используется как иллюстрация и подписана соответствующим образом. Вспомогательные SVG — условные композиции, не фотографии объекта, не архивные документы и не архитектурные проекты.

Подготовьте подтверждённые фотографии усадьбы или утверждённые визуализации в WebP/AVIF и сохраните в `assets/`. Измените `src`, `alt` и подпись в `index.html`, а также `image` и оговорки в данных модальных окон `script.js`. Для афиши используйте кадры формата примерно 3:2; для ботанического этюда — вертикальный кадр. CSS `object-fit` и `object-position` определяют кадрирование. Не заменяйте материалы фотографиями других усадеб под видом Михайловского.

## Доступность и интерфейс

- Ссылка пропуска навигации, видимый фокус и семантические разделы.
- Мобильное меню закрывается по Escape, возвращает фокус и блокирует фоновый контент.
- Модальные окна используют нативный `dialog`, закрываются по Escape, крестику, кнопке или клику по фону и возвращают фокус на исходную кнопку.
- Фильтры афиши сообщают состояние через `aria-pressed`; число результатов озвучивается через `aria-live`.
- Вкладки маршрутов поддерживают стрелки, Home и End.
- FAQ использует нативные `details/summary`.
- При `prefers-reduced-motion: reduce` анимации и плавная прокрутка отключаются.
- Без JavaScript основной контент, якорные ссылки и FAQ остаются доступны; дополнительные интерактивные функции требуют JavaScript.
